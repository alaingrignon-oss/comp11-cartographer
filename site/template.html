Deterministic engine

The map's structural promises are enforced, not asserted. package/engine/verify_map.py — pure standard library, no model, no network:

python3 package/engine/verify_map.py             # 7 gates: grammar · linkage · boundaries · ledger join · tombstones · locators · snapshot
python3 package/engine/verify_map.py --selftest # corrupts a throwaway copy 5 ways — every gate must fire

Model-agnostic by construction: cold-reader walks are plain prompts + file packets that any local or hosted model can execute. The same predeclared-question / matched-packet / mechanical-scoring pattern generalizes to any task where you need to prove a context tool helps. See package/engine/README.md.

Receipts

Selected raw evidence from the matched-packet cold-reader pilot (36 tasks, two arms, two repetitions, predeclared key). Full receipts page: docs/receipts.md.

  • Necessity: the unaided reader burned ~18 file opens and greps on the claims question and still never stated the required Does-not-hit boundary (both repetitions); the armed reader opened one card + four cited locators and stated it verbatim.
  • Drift advantage: after a file move + heading rename, the baseline dead-ended on a 240-line read of a file whose heading no longer exists ("requires re-pointing"); both armed readers resolved the same noun via updated locator + alias with on-disk verification. Strictly better, both repetitions.
  • Discipline: 18/18 cartographer-arm walks stopped within two hops; zero sibling-card loads; zero identity-safety or truth-safety violations across all 36 transcripts.
  • Self-correction: the map's first ratification audit blocked all three cards because financial redaction had deleted the offer rows — and the verdict was accepted, the packet re-cut, and only then did coordinates issue. A missing artifact is not a missing fact.
  • Benchmark totals: 18/18 HIT (100%; safety-critical 8/8) · parity 14/14 vs 10/14 · median context bytes −44.9% · median files opened 2 vs ~5–6.5 · independently audited: "stands with listed corrections; no threshold impact."
